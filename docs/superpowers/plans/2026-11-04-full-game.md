# Roman Mosaic Workshop: Full Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the tile-laying prototype into the complete game described in the overview: a workshop hub, commissions and restorations, a design table, laying, grout and polish, reveals, a business with a rival, a story through four chapters, and a town that fills with your floors.

**Architecture:** Godot 4.7 in 2D with GDScript. Game state lives in autoloads (`Data`, `Game`, `Saves`, `Settings`, `Audio`, `Nav`), and each screen is one scene script that `Nav` swaps in. All game data is in JSON under `game/data/`. The interface is pixel art drawn at 480 by 270 and scaled up by a whole number, while floors render at full resolution underneath.

**Tech Stack:** Godot 4.7.2 (GL Compatibility), GDScript, Python 3 tools with numpy, Pillow, soundfile and scipy, PixelLab API for figure art, CC0 recordings from Freesound.

**Spec:** `Overview.md` in the project root.

## Global Constraints

- Prices in docs are CAD. In-game money is denarii.
- Markdown docs: no em dashes, dollar signs written as `\$`.
- Code comments only for a non-obvious reason, one line, present tense.
- No timers and no failure states for the player. A poor floor pays less; it never loses the game.
- The game opens in a window, and F11 toggles full screen.
- All balance numbers live in `game/data/*.json`, never in code.
- Every screen works with the mouse alone. Controller support is added in the last task.
- No commits unless Evan asks.
- Headless tests: `Godot_v4.7.2-stable_win64_console.exe --headless --path game --script res://tests/test_logic.gd` must print `ALL TESTS PASSED`.
- After any picture or sound change: `--headless --path game --import`.

## Review Focus

1. A design with no motifs, or a motif dragged off the floor plan, must still compose and lay. Pinned in Task 3.
2. A save made in an earlier chapter, or a missing or corrupt save file, must load or fall back without losing other slots. Pinned in Task 1.
3. A player who can't afford stone for a design must be told before laying, and offered a cheaper stone. Pinned in Task 6.
4. Huge floors (200 tiles across) must not freeze the window while the layout is worked out. Pinned in Task 4.
5. Refusing every job, or asking far too much, must never strand the player without work the next day. Pinned in Task 6.

### Task 2: Motif pictures and borders

**Files:**
- Create: `tools/art/make_motifs.py`, `assets/art/motifs/*.png`, `data/motifs.json`, `data/borders.json`, `scripts/design/{motif_library,border_painter}.gd`

**Interfaces:**
- Produces: motif PNGs whose pixels are role colours: role 1 pure red, 2 green, 3 blue, 4 yellow, 5 magenta, 6 cyan, transparent = no tile. `motifs.json` gives each `{id, name, kind: picture|pattern, file, roles: {"1": "body", ...}, stones: {"1": "blue_glass", ...}, tier, tags, cost}`.
- Produces: `MotifLibrary.mask(id: String, size_px: Vector2i, rot: int, flip: bool) -> PackedByteArray` of role numbers, upscaled smoothly (each role mask resized with bilinear filtering, thresholded at 0.5).
- Produces: `BorderPainter.paint(img_labels: PackedByteArray, w: int, h: int, px: int, border: Dictionary)` for border ids `plain, key, wave, braid, chequer, triangles, dentil, ivy` at any band width.

- [ ] Step 1: Write `test_motif_mask_roles` (dolphin at 60 by 40 px contains roles 1 and 3, nothing outside 0 to 6) and `test_border_lengths` (every border fills its band on a 100 by 70 and a 41 by 23 tile floor, and the inner field stays empty).
- [ ] Step 2: Run, expect FAIL.
- [ ] Step 3: `make_motifs.py` draws the geometric patterns by code: rosette, star, knot, pelta, sun, flower, shell, wheel. PixelLab pixen draws the figures at 64 by 64, flat colours, then quantised to roles: dolphin, fish, octopus, bird, dog with "CAVE CANEM", loaves, amphora, grapes, Medusa, lion, deer, boat. Log every PixelLab cost to `tools/art/ledger.csv`, and keep the total under \$1.50 USD.
